Four things these screens decide that Section 1 didn't

  1. Branch prefix becomes an executed signal. It is the only proof Codex ran here — no bot commits, no agent app IDs. It needs head.ref added to prSchema in normalize.ts and a column on pull_requests. It is also the weakest signal in the set — anyone can name a branch codex/ — so the card shows the PR count rather than asserting confidence.
  2. Declined signals are shown, not hidden. AGENTS.md exists here but is written by next dev. Silently dropping a file the user can see in their own repo reads as a bug; saying why we declined it is what makes the detector arguable rather than mysterious.
  3. “Never scanned” is its own state, not an empty table — the same distinction evidenceStatus already draws between unconfigured and complete.
  4. The rail needs an order and a cap. Beside the content column it has room for four rows. Sort is: ran before set-up, then by last seen. Everything past four collapses into +n more — not for want of space now, but because this is a summary and the detail page is one click away.
